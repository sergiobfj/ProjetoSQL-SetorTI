# ProjetoSQL - SetorTI

Este é um projeto de banco de dados SQL desenvolvido no **MySQL Workbench**, com o objetivo de praticar e consolidar meus conhecimentos em SQL, baseando-me nas aulas da **DIO (Digital Innovation One)**.

## 🧠 Objetivos do projeto

- Praticar a criação de banco de dados e tabelas
- Utilizar chaves primárias e estrangeiras
- Modelar relacionamentos entre entidades
- Inserir e consultar dados com `INSERT` e `SELECT`

## 🗂 Estrutura do banco

O projeto simula uma estrutura básica de um setor de TI com duas entidades principais:

- `Colaborador`: contém CPF, nome e idade
- `Mouse`: registra marca, cor e a quem o mouse pertence (via CPF)

## 📄 Arquivo incluído

- `setorTI.sql`: script completo com os comandos SQL para:
  - Criar o banco de dados `setorTI`
  - Criar tabelas
  - Inserir registros
  - Consultar os dados

## 🚀 Como executar

1. Abra o **MySQL Workbench**
2. Copie e cole o conteúdo de `setorTI.sql` (ou importe o arquivo)
3. Execute os comandos para criar e popular as tabelas
4. Use os `SELECT` para visualizar os dados inseridos
